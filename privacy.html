Privacy Policy

Effective date: October 20, 2026 · Application: LoFi YouTube Bot

This policy covers LoFi YouTube Bot, a personal-use desktop application operated by Thegreatmen. The application uses YouTube API Services to manage channels authorized by the operator.

Information accessed and stored

  • Google authorization data: OAuth access and refresh tokens, authorization scopes, client configuration and connection status. Google handles sign-in; the application does not collect Google passwords.
  • YouTube API data: authorized channel identifiers and titles; video identifiers, titles, descriptions, thumbnails, privacy settings, publication schedules, durations and upload or processing status used by the workflow.
  • Production and Telegram data: owner and chat identifiers used for access control and replies; submitted themes, project instructions, media files, approval records, job status, upload-session information and diagnostic logs.

How information is used

Information is used to identify the authorized channel, prepare and review content, upload approved videos, update video details, manage publication schedules, verify results and recover interrupted jobs. Google user data is not sold, used for advertising profiles, or used to train generalized artificial intelligence models.

The application’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Permissions requested

  • youtube.upload — upload approved videos.
  • youtube.readonly — read authorized channel and video information for checks and status.
  • youtube.force-ssl — manage authorized YouTube content, including supported updates to video details and publication settings. This Google permission is broader than uploading alone.

Storage, services and sharing

Connection credentials are stored in a local configuration file. Production records and media are stored on the operator’s computer, connected drives and any backups maintained by the operator. The desktop application uses local file access permissions for its connection file; this policy does not claim that all local disks or backups are encrypted.

Google receives authorization requests and YouTube API operations, including uploaded media and video details. Telegram receives messages, previews, project details and status information sent through the bot’s owner-controlled workflow. Content published or scheduled on YouTube is governed by its selected visibility settings. These services process information under their own policies: Google Privacy Policy and Telegram Privacy Policy.

This documentation site is hosted by GitHub Pages. It has no login form, analytics script, advertising integration or application-set tracking cookies. GitHub may process normal hosting request information under the GitHub Privacy Statement. The site does not receive the desktop application’s OAuth tokens or private production files.

Retention and deletion

Connection information is retained while the authorized connection is in use. Project and recovery files remain in the operator’s local project storage or backups until the operator removes them. This website does not offer an automatic data-deletion service.

The operator can stop the application, revoke Google access, remove the local connection credentials, and delete the associated local API records, Telegram messages and backup copies as appropriate. Revoking access stops future authorized API access; it does not automatically erase existing local records or delete videos already uploaded to YouTube. YouTube videos can be managed separately in YouTube Studio.

Access can be revoked through Google account permissions. For a deletion request or privacy question, contact the operator using the support email displayed on the Google consent screen. Public documentation questions can be opened in the issue tracker; do not post private account information, credentials or tokens there. The operator is responsible for handling deletion requests and applicable API-data retention requirements.

Policy changes

Changes to data practices will be reflected here with an updated effective date. Additional consent will be requested where required before using Google user data for a new purpose.
